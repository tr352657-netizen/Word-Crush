# Turbo Clash Online

لعبة سباق ثلاثية الأبعاد تجريبية متعددة اللاعبين، تستخدم HTML وCSS وJavaScript وThree.js في المتصفح، وNode.js وSocket.IO للغرف الخاصة ومزامنة اللاعبين.

## تحسينات التحكم والسيارات

- أضيفت ست سيارات واقعية معروفة يمكن اختيارها قبل إنشاء الغرفة أو الانضمام إليها: **Toyota GR Supra MK5**، و**Nissan GT-R R35**، و**Porsche 911 GT3**، و**Lamborghini Huracán**، و**Ford Mustang GT**، و**BMW M4 Competition**.
- كل طراز له نسب مختلفة للهيكل والسقف والمقدمة والمصابيح والشبك والعجلات والجناح؛ جميعها مجسّمات ثلاثية الأبعاد مبنية برمجيًا عبر Three.js ولا تحتاج ملفات موديلات إضافية.
- هذه مجسّمات مبسّطة مستوحاة من السيارات الحقيقية وليست موديلات CAD أصلية أو نسخًا تجارية دقيقة.
- اختير الطراز في شاشة البداية، ويرسل مع بيانات اللاعب، لذلك تظهر سيارة كل لاعب في قائمة الغرفة وفي السباق.
- التوجيه أصبح تدريجيًا وسلسًا مع استجابة تعتمد على السرعة؛ يحسب الخادم انحراف المسار بدل الاعتماد على قيمة الممر القادمة من المتصفح وحدها.
- دعم لوحة المفاتيح: الأسهم أو `W/A/S/D`، والتعزيز بزر `Space`، والدرفت بزر `Shift` أو `X`.
- على الهاتف توجد أزرار ضغط مستمر للتوجيه والتسارع والفرامل والدرفت، مع زر مستقل للتعزيز. تدعم اللعبة أيضًا وحدات تحكم متوافقة مع Gamepad API في المتصفح.
- جرى تثبيت مواقع العوائق ومعززات السرعة لتكون متطابقة بين اللاعبين بدل توزيعها عشوائيًا لكل عميل.


## ما الجديد في إعدادات عدد اللاعبين؟

- يمكن لمضيف الغرفة اختيار سعتها من قائمة تُحمّل مباشرة من الخادم.
- الحد الافتراضي للغرفة الواحدة هو **64 لاعبًا** بدلًا من 12.
- يمكن رفع الحد إلى 256 لاعبًا في الغرفة عن طريق إعداد الخادم، لكن ذلك لا يعني أن أي استضافة أو جهاز عميل سيتحمل هذا العدد بالضرورة.
- يوجد أيضًا حد إجمالي افتراضي قدره 500 لاعب عبر كل الغرف، قابل للتعديل.
- معدل إرسال لقطات حالة السباق ومعدل المحاكاة قابلان للضبط لتقليل ضغط الشبكة أو رفع الاستجابة.
- يتحقق الخادم من سعة الغرفة وحد اللاعبين الإجمالي؛ لا تعتمد الحماية على القائمة في المتصفح فقط.

## المتطلبات

- Node.js 18 أو أحدث.
- اتصال إنترنت لتحميل Three.js من CDN وللاتصالات بين اللاعبين.

## التشغيل على الكمبيوتر

1. فك ضغط المشروع.
2. افتح Terminal أو PowerShell داخل مجلد `turbo-clash-online`.
3. ثبّت المكتبات:

   ```bash
   npm install
   ```

4. شغّل الخادم:

   ```bash
   npm start
   ```

5. افتح `http://localhost:3000`.
6. أنشئ غرفة واختر السعة، ثم شارك كود الدخول مع أصدقائك.

## ضبط السعة حسب الخادم

يمكن وضع المتغيرات التالية في إعدادات الاستضافة أو ملف `.env` إذا كانت الاستضافة تشغّل ملفات البيئة تلقائيًا. في التشغيل المحلي، صدّر المتغيرات من الطرفية قبل تشغيل `npm start`؛ المشروع لا يحمّل ملف `.env` تلقائيًا.

| المتغير | الافتراضي | المعنى |
|---|---:|---|
| `MAX_PLAYERS_PER_ROOM` | `64` | الحد الأقصى للغرفة الواحدة، بين 2 و256 |
| `MAX_TOTAL_PLAYERS` | `500` | الحد الإجمالي للاعبين في كل الغرف، بين 1 و20000 |
| `SNAPSHOT_RATE_HZ` | `10` | عدد تحديثات حالة السباق المرسلة في الثانية، بين 2 و20 |
| `SIMULATION_RATE_HZ` | `20` | عدد خطوات محاكاة الخادم في الثانية، بين 10 و60 |
| `PORT` | `3000` | منفذ HTTP؛ غالبًا تحدده الاستضافة تلقائيًا |
| `CORS_ORIGIN` | غير محدد | اختياري: أصول مسموح بها مفصولة بفواصل إذا كان الويبSocket يأتي من أصل مختلف |

### مثال: رفع الحد إلى 128 لاعبًا بالغرفة

في لوحة إعدادات الاستضافة أضف:

```text
MAX_PLAYERS_PER_ROOM=128
MAX_TOTAL_PLAYERS=1000
SNAPSHOT_RATE_HZ=10
SIMULATION_RATE_HZ=20
```

أعد تشغيل الخدمة أو أعد نشرها. ستقرأ الواجهة الحد الجديد من `/api/config` وتحدّث قائمة اختيار سعة الغرفة تلقائيًا.

على Windows PowerShell، لتجربة هذه القيم لجلسة الطرفية الحالية:

```powershell
$env:MAX_PLAYERS_PER_ROOM="128"
$env:MAX_TOTAL_PLAYERS="1000"
$env:SNAPSHOT_RATE_HZ="10"
$env:SIMULATION_RATE_HZ="20"
npm start
```

على macOS/Linux:

```bash
MAX_PLAYERS_PER_ROOM=128 MAX_TOTAL_PLAYERS=1000 SNAPSHOT_RATE_HZ=10 SIMULATION_RATE_HZ=20 npm start
```

**تنبيه أداء:** لا تبدأ مباشرة بمئات اللاعبين على خادم صغير. جرّب 32 ثم 64 لاعبًا، وراقب المعالج والذاكرة واستخدام الشبكة وزمن الاستجابة. إرسال حالة كل لاعب إلى بقية لاعبي الغرفة يزيد الحمل مع ارتفاع عدد اللاعبين. رفع الأرقام يحدد السعة المسموحة برمجيًا، لكنه لا يضيف موارد فعلية إلى الخادم.

## تجربة أكثر من لاعب

- للاختبار على الجهاز نفسه، افتح الموقع في أكثر من نافذة متصفح أو ملف شخصي.
- على شبكة محلية، شغّل الخادم على جهاز واحد وافتح `http://IP-ADDRESS:3000` من الأجهزة الأخرى بعد السماح باتصال Node.js في جدار الحماية.
- `localhost` يعني الجهاز الحالي فقط ولا يصلح كرابط ترسله إلى أصدقائك عن بُعد.

## النشر على الإنترنت

1. ارفع ملفات المشروع إلى مستودع Git.
2. أنشئ خدمة Web Service تدعم Node.js وWebSocket لدى مزود استضافة.
3. Build command: `npm install`
4. Start command: `npm start`
5. اضبط متغيرات السعة في لوحة الاستضافة عند الحاجة.
6. استخدم رابط HTTPS الذي تمنحه الاستضافة وشاركه مع أصدقائك.

## الملفات

- `server.js`: إعداد السعة، الغرف، التحقق من حدود اللاعبين، ومحاكاة السباق ومزامنته.
- `public/index.html`: واجهة اللعبة وغرفة الانتظار.
- `public/style.css`: تنسيق الواجهة وقائمة اللاعبين.
- `public/game.js`: مشهد Three.js، نماذج السيارات الستة، التحكم السلس، العقبات وترتيب السباق.
- `package.json`: المكتبات وأوامر التشغيل.
- `.env.example`: مثال لإعدادات الخادم.

## حدود النسخة التجريبية

هذه نسخة أولية قابلة للتطوير وليست لعبة تجارية مكتملة. نماذج السيارات مبسطة ومولدة بالكود، وليست بديلًا عن ملفات 3D عالية الدقة. الطريق والعقبات تجريبية، والتصادمات والطرق المتفرعة لم تُربط بعد بمحاكاة تنافسية كاملة على الخادم. قبل فتحها للجمهور، اختبرها تحت حمل فعلي وطوّر التحقق من التصادمات والاختصارات ومكافحة الغش.
